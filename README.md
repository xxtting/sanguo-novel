# 穿越三国：天才阿元的逆袭

## 简介

现代天才高材生阿元，精通历史、化学、军事科技等各项知识，德智体兼修。意外穿越到汉末三国初期，凭借超前的知识和技术，在这个英雄辈出、群雄逐鹿的乱世中，扭转乾坤，建立自己的势力，与多位红颜知己共度余生。
